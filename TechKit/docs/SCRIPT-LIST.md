# Starter script library

| Category | Script | Admin | Changes | Where |
|---|---|---|---|---|
| Helpdesk | **Clear Temp Files**: Deletes old files from Windows Temp and every user's Temp folder, optionally browser caches. Locked files are skipped. Use What-If to see how much would be freed. | Yes | Yes | Local, Remote |
| Helpdesk | **Time Zone Converter**: Converts a time (or now) between time zones, for scheduling with users and vendors in other regions. Accepts partial zone names like "Pacific" or "Tokyo". | No | No | Local |
| Helpdesk | **Disk Space Report**: Lists every fixed drive with size, free space and percent free, and flags drives below your threshold. | No | No | Local, Remote |
| Helpdesk | **Folder Permissions Report**: NTFS permissions for a folder, plus only the subfolders whose permissions differ (inheritance broken or extra explicit entries). Hides SYSTEM, CREATOR OWNER and other noise. Can also write the two CSV files (root and subfolders). | Yes | No | Local, Remote |
| Helpdesk | **Folder Sizes (incl. size on disk)**: Sizes of the folders under a path, with optional size on disk so you can see that a 20 GB OneDrive folder only uses 2 GB locally. Good for low-disk tickets and file migrations. | No | No | Local, Remote |
| Helpdesk | **Installed Software**: Lists installed programs (64-bit, 32-bit and per-user) with version, publisher and install date. Filter by name with wildcards. | No | No | Local, Remote |
| Helpdesk | **System Info Summary**: One-page summary of a PC: model, serial, Windows version, uptime, CPU, memory, disk, signed-in user, domain, IP and pending reboot. | No | No | Local, Remote |
| Helpdesk | **Force Group Policy Update**: Runs gpupdate /force for computer and/or user policy and shows which GPOs applied. Remote runs refresh computer policy for that PC. | Yes | Yes | Local, Remote |
| Helpdesk | **User Profile Cleanup**: Lists Windows user profiles with their real last logon and logoff times (from the profile registry, not the unreliable folder dates) and removes profiles idle longer than N days. Leaves loaded, special and excluded profiles alone. Lists only unless you tick RemoveProfiles. | Yes | Yes | Local, Remote |
| Helpdesk | **Fix Print Spooler**: Shows printers and stuck jobs, then stops the Print Spooler, clears the queue folder and starts it again. Tick List only to just look. | Yes | Yes | Local, Remote |
| Helpdesk | **Repair Windows (DISM + SFC)**: Runs DISM to repair the Windows component store, then System File Checker. Scan only checks without repairing. Can take 10-30 minutes. | Yes | Yes | Local, Remote |
| Helpdesk | **Reset Network Stack**: Fixes common "no internet" problems on this PC: flush DNS, renew DHCP, and optionally reset Winsock and TCP/IP (those two need a restart). Local only because it can drop the connection. | Yes | Yes | Local |
| Helpdesk | **Reset Windows Update**: Fixes stuck Windows Update: stops the update services, renames the SoftwareDistribution and catroot2 caches, and starts the services again. | Yes | Yes | Local, Remote |
| Helpdesk | **Who Has This File Open?**: Tells you whether a file (or the files in a folder) is locked and by what: local programs (via Windows Restart Manager) and, on a file server, which user and PC have it open over the network. Can close the network handles or stop the locking program. | Yes | Yes | Local, Remote |
| Helpdesk | **Watch Log File (live)**: Shows the last lines of a log and keeps following it live, like Get-Content -Tail -Wait, with errors in red and warnings in yellow. Presets for CBS, DISM, Intune, ConfigMgr, Windows Setup and the firewall log. Press Stop to end. | Yes | No | Local, Remote |
| Network | **Active Connections (netstat)**: Lists TCP connections or listening ports with the program that owns each one. Handy for "what is talking to the internet?" and "what is listening on this port?". | No | No | Local, Remote |
| Network | **Network Configuration**: Shows each connected adapter with IP address, subnet, gateway, DNS servers, DHCP state, MAC, link speed and network profile (Public/Private/Domain). | No | No | Local, Remote |
| Network | **Wi-Fi Status**: Shows the current Wi-Fi connection (SSID, signal, band, channel, speed, security) and optionally nearby networks and saved profiles. Passwords are never shown. | No | No | Local, Remote |
| Network | **Ping Sweep (Find Devices)**: Pings every address in a subnet at once and lists the devices that answer, with host names and MAC addresses. Leave Subnet empty to scan this PC's own network. | No | No | Local, Remote |
| Network | **DNS Lookup**: Looks up DNS records (A, MX, TXT, SPF, DMARC and more) for a name and compares the answer from this network's DNS with public resolvers. | No | No | Local, Remote |
| Network | **Connectivity Check**: Step-by-step "is it the network?" test: adapter, gateway, DNS servers, name resolution, internet ping, HTTPS, Microsoft 365 endpoints and the public IP address. | No | No | Local, Remote |
| Network | **Quick Speed Test**: Measures latency, download and optional upload speed against Cloudflare's speed test service. Good for "the internet is slow" tickets. | No | No | Local, Remote |
| Network | **Port Check**: Tests TCP ports on one or more hosts in parallel (for example RDP 3389, SMB 445, HTTPS 443). Accepts lists and ranges like 80,443,8000-8010. | No | No | Local, Remote |
| Network | **Traceroute**: Traces the network path to a host hop by hop with latency and names, showing where traffic slows down or stops. | No | No | Local, Remote |
| Network | **TLS Certificate Check (Python)**: Connects to HTTPS hosts and reports certificate expiry, days left and issuer, flagging invalid or soon-to-expire certificates. Example Python script (needs Python on the PC or in Runtimes\python). | No | No | Local |
| Security | **BitLocker Status**: Shows encryption status, method and key protectors for every drive. Can also display recovery passwords so you can record them (handle with care). | Yes | No | Local, Remote |
| Security | **Antivirus / Defender Status**: Shows Microsoft Defender health (real-time protection, signature age, last scans, tamper protection) and any other antivirus registered with Windows Security. Optionally lists recent detections. | No | No | Local, Remote |
| Security | **Failed Logons & Lockouts**: Summarizes failed sign-ins (event 4625) and account lockouts (4740) from the Security log, grouped by account and source, with the reason in plain English. | Yes | No | Local, Remote |
| Security | **Firewall Status**: Shows whether Windows Firewall is on for the Domain, Private and Public profiles, any third-party firewall, and optionally the inbound rules that allow traffic from anywhere. | No | No | Local, Remote |
| Security | **Local Administrators**: Lists every member of the local Administrators group (users, groups, domain and Entra ID accounts) and highlights anything unexpected. | No | No | Local, Remote |
| Security | **Patch Status**: Shows the Windows build, recent updates from Windows Update history, days since the last update and pending reboot. Optionally searches for missing updates (local only, slower). | No | No | Local, Remote |
| Security | **Scheduled Tasks Audit**: Lists non-Microsoft scheduled tasks with who they run as, what they run, last result and next run. Flags tasks that run from user-writable folders or as SYSTEM. | Yes | No | Local, Remote |
| Security | **Secure Boot Certificate Status (2023 CA)**: A readable wrapper for the Secure Boot one-liners: is Secure Boot on, are the new 2023 Microsoft certificates (KEK and DB) in firmware before the 2011 ones expire, what the Windows servicing status says, and recent Secure Boot update events. | Yes | No | Local, Remote |
| Security | **Shared Folders & Permissions**: Lists SMB shares with their share permissions, flags shares open to Everyone or Authenticated Users, and reports whether SMBv1 is enabled. | Yes | No | Local, Remote |
| Security | **Security Quick Check**: Checks about 18 common hardening settings (SMBv1, LLMNR, NetBIOS, WDigest, LSA protection, UAC, RDP NLA, firewall, Defender, BitLocker, TLS 1.0, PowerShell 2, patch age and more) and gives PASS / WARN / FAIL with a fix for each. | Yes | No | Local, Remote |
| Active Directory | **SID and Name Lookup**: Converts user or group names to SIDs and SIDs back to names (handy for orphaned SIDs in permissions and logs). Also shows the Unix uidNumber/gidNumber when the domain has them. No RSAT needed. | No | No | Local, Remote |
| Active Directory | **Disable User (Offboarding)**: Offboards an AD user: disables the account, optionally resets the password, removes group memberships (saved in the output as a record), stamps the description and moves it to a disabled-users OU. | No | Yes | Local, Remote |
| Active Directory | **AD Changes Report**: What changed in Active Directory: new accounts, accounts expiring soon, recently disabled, and (compared with the last run) moved, renamed and deleted accounts. Export to HTML for a weekly e-mail so you hear about starters and leavers. | No | No | Local, Remote |
| Active Directory | **Domain Health Summary**: Domain and forest overview: functional levels, FSMO role holders, every domain controller with site, OS and reachability, plus replication summary (repadmin) and optional dcdiag. | No | No | Local, Remote |
| Active Directory | **Group Membership**: Shows every group a user belongs to (including nested groups), or every member of a group (recursively). Use it for "why can't they see the share?" and access reviews. | No | No | Local, Remote |
| Active Directory | **Locked-Out Users & Lockout Source**: Lists locked-out accounts and, by reading lockout events (4740) on the PDC emulator, which computer caused each lockout. Helps find the old phone or mapped drive with a stale password. | No | No | Local, Remote |
| Active Directory | **Password Expiry Report**: Lists users whose passwords expire within N days or have already expired, plus accounts set to never expire. Uses the computed expiry so fine-grained policies are respected. | No | No | Local, Remote |
| Active Directory | **Stale Users & Computers**: Finds enabled user and computer accounts that have not logged on for a number of days (or never), using lastLogonTimestamp. Good for cleanup and license reviews. | No | No | Local, Remote |
| Active Directory | **AD User Lookup**: Everything a helpdesk call needs about a user: enabled, locked out, password last set and expiry, last logon, bad password count, manager, OU and groups. Accepts logon name, UPN, email or a wildcard search. | No | No | Local, Remote |
| Active Directory | **LAPS Password (Active Directory)**: Reads the local administrator password that LAPS stored in Active Directory for a computer: Windows LAPS (including encrypted passwords) or legacy Microsoft LAPS. Shows when it expires. You need LAPS read rights on the computer's OU. | No | No | Local, Remote |
| Active Directory | **Privileged Groups Audit**: Everyone in Domain Admins, Enterprise Admins, Schema Admins, Administrators, the Operators groups, DnsAdmins and Group Policy Creator Owners (nested members included), with last logon and password age. Save a baseline and later runs show who was added or removed. | No | No | Local, Remote |
| Active Directory | **Install RSAT AD Tools**: Installs the Active Directory PowerShell module (RSAT) on this PC so the AD scripts can run here. Windows 10/11 downloads it from Windows Update; servers add the feature. Optionally adds Group Policy tools. | Yes | Yes | Local |
| Active Directory | **New User (Active Directory onboarding)**: Adaxes-style onboarding from a client rules file: builds the logon name, UPN and e-mail from the naming convention, picks the OU and groups for the department, generates a password, sets the manager, optionally copies another user's groups and starts an Entra Connect sync. Run What-If first to preview. | No | Yes | Local |
| Active Directory | **Reset AD Password**: Resets a user's Active Directory password, optionally requiring a change at next logon and unlocking the account. Leave the password empty to generate a strong one. | No | Yes | Local, Remote |
| Active Directory | **Unlock AD Account**: Shows a user's lockout status and bad-password details, then unlocks the account. Leave Identity empty to unlock nothing and just list everyone who is locked out. | No | Yes | Local, Remote |
| Microsoft 365 | **Bulk Add Users to Group / Team**: Adds (or removes) a list of users to a Microsoft 365 group, Team, security group or, with Exchange connected, a distribution list. Paste UPNs or point at a CSV. Adding to a Team's group adds them to the Team. | No | Yes | M365 |
| Microsoft 365 | **Activate PIM Role**: Lists the Entra admin roles you are eligible for through Privileged Identity Management and activates one for a few hours with a justification, without clicking through the portal. Leave Role empty to just list. | No | Yes | M365 |
| Microsoft 365 | **Find Tenant ID**: Looks up a Microsoft 365 tenant from any of its domains without signing in: tenant ID, region, whether sign-in is cloud (managed) or federated (ADFS / third-party IdP), and the brand name. Handy before connecting to a new client. | No | No | Local |
| Microsoft 365 | **LAPS Password (Entra ID / Intune)**: Reads the local administrator password that Windows LAPS backed up to Entra ID for a cloud-joined or hybrid device, with the backup date. Needs the "Cloud Device Administrator" or "Intune Administrator" role (or a custom role with LAPS read). | No | No | M365 |
| Microsoft 365 | **Exchange RBAC Lookup**: Answers "which Exchange role lets someone run this cmdlet?", "what can this role do?" and "which roles does this person have?". Useful when building least-privilege delegation for helpdesk staff or app registrations. | No | No | M365 |
| Microsoft 365 | **Intune Devices Report**: Intune-managed devices with user, serial number, model, OS version, compliance, encryption and last check-in. Flags stale devices. Search by device name, user or serial to answer "which laptop does this person have?". | No | No | M365 |
| Microsoft 365 | **Guest Users Report**: Lists external guest accounts with invite status, age and last sign-in so you can clean up stale guests. | No | No | M365 |
| Microsoft 365 | **License Report**: Lists users with their licenses. Finds wasted licenses on blocked accounts and members with no license. Export to CSV for billing reviews. | No | No | M365 |
| Microsoft 365 | **MFA Registration Report**: Shows which users have registered MFA, their default method and whether they are admins. Uses the Entra registration report, or checks each user if that report is not licensed. | No | No | M365 |
| Microsoft 365 | **User Sign-in Log**: Recent sign-ins for one user with app, IP, location, device, result and Conditional Access outcome. Lists the countries seen so unusual locations stand out. Needs Entra ID P1. | No | No | M365 |
| Microsoft 365 | **Tenant Overview**: First thing to run on a new client: organization name, domains, directory sync, license counts (used / available), user and guest totals, Global Admins and security defaults. | No | No | M365 |
| Microsoft 365 | **M365 User Lookup**: Everything about one Microsoft 365 user: sign-in status, licenses, MFA methods, last sign-in, password age, manager, groups and (if Exchange is connected) mailbox size and forwarding. | No | No | M365 |
| Microsoft 365 | **Forwarding & Inbox Rules Audit**: Finds mailboxes that forward mail (mailbox forwarding and inbox rules), marks external destinations, and flags rules that delete or hide mail. A key check after a phishing or business-email-compromise incident. | No | No | M365 |
| Microsoft 365 | **Mailbox Permissions**: Who has Full Access, Send As and Send on Behalf on a mailbox, or on every mailbox (slower). Answers "who can read this inbox?". | No | No | M365 |
| Microsoft 365 | **Mailbox Size Report**: Size, item count, quota used and last logon for every mailbox (or the largest N), with optional archive sizes. Finds mailboxes about to hit their quota. | No | No | M365 |
| Microsoft 365 | **New User (Microsoft 365 onboarding)**: Adaxes-style cloud onboarding from a client rules file: builds the UPN and e-mail from the naming convention, creates the account, assigns licenses, adds the department's groups, Teams and SharePoint sites, sets the manager and (with Exchange connected) adds distribution lists. Run What-If first. | No | Yes | M365 |
| Microsoft 365 | **Create App Registration for Tech Kit**: Creates an Entra app registration so you can sign in to a client tenant without prompts next time: Graph application permissions with admin consent, a self-signed certificate (saved as a .pfx in Certs), optional client secret, Exchange Online and other admin roles, and a saved Tech Kit tenant profile. Run once per tenant as a Global Admin. | No | Yes | M365 |
| Microsoft 365 | **Reset M365 Password**: Resets a cloud user's password (generates a strong one if you leave it empty), optionally forces a change at next sign-in and signs them out everywhere. Users synced from AD must be reset in AD instead. | No | Yes | M365 |
| Microsoft 365 | **Block Sign-in & Revoke Sessions**: Compromised account or urgent leaver: blocks sign-in, revokes every session and refresh token, and optionally resets the password and removes mailbox forwarding. Run it first, investigate after. | No | Yes | M365 |
| Microsoft 365 | **Grant or Remove Mailbox Access**: Gives (or takes away) Full Access, Send As or Send on Behalf on a mailbox or shared mailbox, with auto-mapping in Outlook. Shows the current permissions first. | No | Yes | M365 |
| Microsoft 365 | **Set Out of Office**: Turns automatic replies on (now or for a date range) or off for any mailbox, for the VIP who forgot before leaving. Shows the current setting first. | No | Yes | M365 |
| Microsoft 365 | **Offboard User (Microsoft 365)**: Adaxes-style leaver workflow: block sign-in, revoke sessions, reset the password, convert the mailbox to shared, give the manager access, set an auto-reply, hide from the address book, remove group memberships and licenses. Every step is listed so the output doubles as the ticket record. Defaults come from the client's rules file. | No | Yes | M365 |
| Servers | **Archive & Clean Old Files**: Zips files older than N days (IIS logs, app logs, exports) into one archive per month and deletes the originals once they are safely in the zip. Or just deletes, or just zips. Use What-If to see how much space you would get back. | Yes | Yes | Local, Remote |
| Servers | **Large Files & Folders**: "The disk is full" helper: biggest folders one level under a path and the largest individual files, skipping folders you cannot read. | Yes | No | Local, Remote |
| Servers | **Expiring Certificates**: Finds certificates in the computer's Personal, Web Hosting and Remote Desktop stores that expire within N days (or already have), with subject names, issuer and private-key status. | No | No | Local, Remote |
| Servers | **Reboot & Shutdown History**: When the computer restarted or shut down, who or what triggered it (Windows Update, a user, a program) and the reason given, including unexpected shutdowns. | No | No | Local, Remote |
| Servers | **Recent Errors & Critical Events**: Groups Critical and Error events from the System and Application logs by source and ID, and calls out crashes, unexpected shutdowns, disk and NTFS problems. | No | No | Local, Remote |
| Servers | **Server Health Check**: One line per server: uptime, CPU, memory, lowest disk, pending reboot, stopped automatic services, errors in the last 24 hours and days since patching, with an overall OK / WARN / FAIL. Put several servers in the Target box. | No | No | Local, Remote |
| Servers | **Server Roles & Apps**: "What does this server do?" Lists installed roles and features, plus quick counts for IIS sites, SQL Server instances, Hyper-V VMs, shares, DHCP scopes and DNS zones when present. | Yes | No | Local, Remote |
| Servers | **Stopped Automatic Services**: Lists services set to start automatically that are not running, skipping ones that normally stop on their own. Use "Start, Stop or Restart a Service" to start one. | No | No | Local, Remote |
| Servers | **Start, Stop or Restart a Service**: Starts, stops or restarts a Windows service by name or display name, shows dependent services first, waits for it to settle and reports the final state. | Yes | Yes | Local, Remote |
| Tech Kit | **Add Script Library from GitHub**: Downloads a GitHub repository of scripts (for example github.com/admindroid-community/powershell-scripts) into the Libraries folder on the USB. It shows up as its own category; run again to update it. Libraries are other people's code: review before use. | No | No | Local |
| Tech Kit | **Put PowerShell 7 on the USB**: Downloads the official PowerShell 7 zip from GitHub and extracts it to Runtimes\pwsh on the USB, so Tech Kit runs on PowerShell 7 even on PCs that only have Windows PowerShell 5.1. | No | No | Local |
| Tech Kit | **View Audit Log**: Shows the Tech Kit audit log (Logs\audit.csv on the USB): every run of a script that makes changes, with who, when, which computer, target, inputs, ticket, approver and result. Filter by date or text and export for the client. | No | No | Local |
| Tech Kit | **Check Script Library**: Self-test for Tech Kit: parses every script, checks the metadata headers, and (if PSScriptAnalyzer is available) checks that each script works on both Windows PowerShell 5.1 and PowerShell 7. Run it after adding scripts. | No | No | Local |
| Tech Kit | **Update USB Modules**: Downloads or refreshes the PowerShell modules carried on the USB (Microsoft Graph, Exchange Online and anything listed in Config\modules.json) from the PowerShell Gallery. Needs internet. | No | No | Local |
| Linux | **Linux Health Check (SSH)**: Checks a Linux server over SSH: OS, uptime, load, memory, full filesystems, failed systemd units, pending reboot, available updates and recent journal errors. Put user@host in the Target box (SSH key sign-in). | No | No | Remote |
